## Keeping repository size small

- Keep these links in Git rather than embedding full-resolution slide images.
- If local copies are needed, export from Canva as **PDF Standard** for sharing, or use compressed PDF output; avoid exporting every slide as a separate PNG.
- Actual PDF/image exports are not included in this commit. The available Canva connector can locate and link designs but does not expose a direct presentation-export/download operation, and the GitHub file operation available here accepts text files only.
