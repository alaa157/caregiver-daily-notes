# Rafeek — selected brand concept

Product name: **Rafeek** (Arabic: **رفيق**) — "a companion".
Tagline: *A companion in every moment of care* / *رفيقك في تفاصيل الرعاية*.

Selected direction: **Concept 03 — The Gather** (Geometric · Intelligent).
Four rounded arc-fragments around a shared centre: a fuller picture emerges
when separate observations are held together. No medical symbolism.

This folder carries only the selected concept. The full exploration (four
concepts, brand sheet, tokens, and the `rafeek-brand-kit.zip` kit) lives on
the `add-brand-files` branch.

Files:
- `symbol.svg` — the mark (pine `#285B45` arcs, clay `#C77F68` centre)
- `app-icon.svg` — rounded-square app icon (pine ground, white mark)
- `logo-horizontal-en.svg`, `logo-horizontal-ar.svg`, `logo-horizontal-bilingual.svg`
- `logo-stacked.svg`, `logo-white.svg`, `logo-black.svg`, `monochrome.svg`
- `concept.svg`, `concept-preview.png` — concept board

Applied in: Android launcher icons + auth mark + `app_name` (EN/AR), web
favicon, sidebar/landing mark, page metadata, and the social preview card.
Brand colors are exploration tokens only; the app themes are unchanged.
